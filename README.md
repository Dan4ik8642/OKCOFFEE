# Лендинг «Ок. о, Кофе!» — Саввино

Готовый статический лендинг без сборщика: откройте `index.html` в браузере.

## Что заложено
- адаптив под мобильные/планшеты;
- мягкие scroll-reveal анимации;
- hero + преимущества + напитки + отзывы + CTA + форма + контакты;
- кнопка маршрута на исходную карточку Яндекс Карт;
- форма с местом для подключения Telegram/CRM/webhook.

## Подключение формы
Откройте `script.js` и укажите адрес обработчика:
`const WEBHOOK_URL = 'https://...'`

## Источники фактов
При подготовке концепта использовались открытые данные:
- карточка кофейни в Яндекс Картах по ссылке заказчика;
- Яндекс-подборки/отзывы по кофейне в Балашихе;
- Restaurant Guru: адрес, график, ориентир среднего чека и опубликованное меню.

Соцсети: в открытой поисковой выдаче не удалось надежно подтвердить официальные аккаунты именно этой точки, поэтому я не стал приписывать кофейне непроверенные ссылки, акции или визуальные материалы.

## Важно
Цены, график и ассортимент могут меняться. Перед публикацией лучше сверить их с владельцем.

## Палитра по логотипу
- основной зелёный: `#5EA18F`
- светлый мятный: `#B0D2CA`
- тёмный зелёный для текста и кнопок: `#203C35`
- фон: `#F4F9F7`
- белый: `#FFFFFF`

Оранжевые акценты из первой версии убраны — теперь весь лендинг собран в фирменной зелёно-мятной гамме логотипа.
